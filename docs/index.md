# FDE와 CS 지식

FDE(Forward Deployed Engineer)는 고객사 현장에 붙어서 제품을 고객의 실제 환경과 데이터에 맞게 동작시키는 엔지니어다. 제품 개발자와 달리 **내가 통제할 수 없는 환경**에서 일한다는 점이 핵심이다. 고객사의 방화벽, 낡은 데이터베이스, 사내 인증 체계, 엑셀로 관리되던 데이터가 모두 작업 대상이 된다.

그래서 FDE에게 필요한 CS 지식은 깊이보다 **폭과 진단 능력**에 가깝다. "왜 안 되는가"를 계층별로 좁혀 나갈 수 있어야 하고, 그 내용을 비개발자인 고객에게 설명할 수 있어야 한다.

| 3 | [데이터베이스와 SQL](./03-database-sql) | 고객 데이터는 어디에 어떤 모양으로 있는가 |

## 각 문서의 구조

모든 문서는 같은 네 칸으로 되어 있다.

1. **개념 요약**: 꼭 알아야 하는 것만 짧게
2. **현장에서 만나는 상황**: 이 지식이 실제로 필요한 순간과 진단 순서
3. **면접 예상 질문**: 질문과 답변 요지
4. **내 프로젝트와의 연결**: 직접 겪은 사례로 채우는 칸

4번 칸은 비워 둔 채로 시작한다. 공부하면서 내 프로젝트에서 같은 문제를 겪은 적이 있는지 떠올려 직접 채우는 것이 이 노트의 목적이다. 면접에서 힘을 갖는 것은 개념 설명이 아니라 "그래서 저는 이렇게 해결했습니다"이기 때문이다.
